Image manipulation scenarios aligned with the "Working with Images" docs.
Most scripts use `examples/Showcase.pdf` and write results to
`output/working-with-images/`. `11_clear_image_clipping.ts` uses
`examples/clipping/invisible-content-clipping-test.pdf` to reveal an image that
is hidden by a clipping path.

- `01_list_images.ts` – list image metadata and coordinates.
- `02_move_image.ts` – reposition the first page image.
- `03_delete_images.ts` – remove all images from a page.
- `11_clear_image_clipping.ts` – remove clipping from a hidden image so it becomes visible.
